How to Import into Xcode:
  1. Download your icon set using Download All iOS Icons.
  2. Download the matching Contents.json using the button above.
  3. In Xcode, expand your project > open Assets.xcassets.
  4. Right click on AppIcon > select Show in Finder.
  5. Replace the contents of AppIcon.appiconset with the generated PNGs and Contents.json.
